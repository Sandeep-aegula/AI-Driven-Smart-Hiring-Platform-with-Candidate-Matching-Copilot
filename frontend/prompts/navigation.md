# HirePilot AI - Navigation Guide ====================================================== ## Main Navigation - Dashboard: Overview and KPIs - Jobs: Job posting management - Candidates: Candidate database and search - Resume Parser: Upload and parse resumes - AI Screening: Automated candidate evaluation - Interviews: Interview scheduling and management - Analytics: Reports and metrics - Employees: Employee management - Settings: Application configuration - AI Copilot: Chat with AI assistant ## Common User Flows ### Hiring a New Employee 1. Jobs → Create Job 2. Jobs → Generate JD (AI) 3. Jobs → Publish Job 4. Resume Parser → Upload Resumes 5. AI Screening → Screen Candidates 6. Candidates → Review Rankings 7. Interviews → Schedule Interviews 8. Interviews → Collect Feedback 9. Reports → Generate Offer Letter 10. Employees → Onboard New Employee ### Analyzing Candidates 1. Resume Parser → Upload Resumes 2. AI Screening → Run AI Screening 3. Candidates → View Match Scores 4. Candidates → Compare Top Candidates 5. Interviews → Schedule Top Candidates ### Managing Jobs 1. Jobs → View All Jobs 2. Jobs → Create New Job 3. Jobs → Edit Job Details 4. Jobs → Generate JD (AI) 5. Jobs → Publish/Close Job ## Quick Tips - Use the AI Copilot (bottom-right icon) for instant help - Upload resumes in bulk for faster processing - Use AI Screening to save time on manual review - Check Dashboard for real-time hiring metrics - Export data to CSV for external analysis
